# 课堂解析与同步笔记

Canvas / 课堂实录侧栏现在默认“生成解析”：配置一次视频模型后，点击即可读取当前完整 MP4 / WebM，从 00:00 处理到结尾，自动关联并显示笔记。原本手动上传视频的入口仍可使用。

v0.6.3：从“我的课堂”打开已有解析，视频右侧直接显示对应的 Type A/B/C 笔记；跟随播放、手动固定阅读、当前讲解高亮、片段提问和伴学全屏已接入。阅读已有笔记无需再次解析，也不额外调用模型。本地保存文件有独立开关。


更新：2026-11-14。课堂视频入口已包含在 v0.6.0 Windows 本地预览包中，GitHub 已发布版本尚未更新。没有采集用户的真实课堂或进行实际模型评分。

## 处理流程

1. 原视频流式上传到本机课堂目录，按容器标识、文件大小和文件名验证。此步骤不调用模型。
2. 用户在课堂页填写独立的 Gemini 密钥，确认发送视频并点击开始，才调用 Google 官方视频接口。密钥只保留在本次任务内存，不读取其他模型密钥或环境密钥。
3. 服务接收原视频，返回真实时长后生成连续的 3、5 或 10 分钟区间，包括不足一段的末尾。默认每秒取一帧并读取音频。
4. 对每个区间分别提取课堂内容、公式、证明、例题、辅助解释、学习目标、练习与待核对事项，校验结构和原视频绝对时间范围后再保存。
5. 完成、失败或取消都尝试清理远端临时视频，再公布最终状态。清理未确认的提示跨重试保留。已完成片段按相同模型和区间长度继续，不重复采集。

后台任务不因页面关闭就自动撤销。关闭软件时请求停止后续处理；已经发送的网络请求可能继续消耗额度，退出后未完成任务需要手动继续。原视频、解析报告和 JSON/Markdown 导出属于独立课堂库，暂不进入原“完整备份学习库”。

## 来源与覆盖的含义

`source_summary` 是模型对课堂原内容的识别；`explanation` 是辅助解读；原课堂练习和补充练习分别标记。两者都是候选内容，不能根据模型置信度宣布数学正确或自动授予掌握。

“时间区间处理比例”表示已完成请求的连续时间范围，不证明所有语句、画面和数学细节已被正确识别。每秒抽样、小字、遮挡、音质、跨段论证和模型输出上限都可能影响内容覆盖。模型应保留缺口和疑问；具体内容通过原视频时间戳回查。原生视频读取也不是逐字转录或形式化证明验证。

## 实现依据

- [Google Files API](https://aistudio.google.com/docs/files)：流式可恢复上传、文件状态轮询和清理。
- [File 元数据](https://aistudio.google.com/api-reference/files#Resource:File)：使用服务端视频时长，不把浏览器估计当作处理完成依据。
- [视频区间与帧率](https://aistudio.google.com/docs/video-understanding#clipping-intervals)：同时读取原视频的声音和抽样画面。
- [Interactions 响应结构](https://aistudio.google.com/api-reference/interactions-api#Resource:Interaction)：固定 `Api-Revision: 2026-05-20`，只读取完成响应的模型输出，不将思考或工具步骤当成课堂笔记。

## 新增：从课堂卡点到下一步学习

“这一步卡住了”连接一条完整过程：选择课堂片段 → 学生描述困惑和已有基础 → 提出可检验的卡点假设 → 给够用的先修与一道检查题 → 学生用自己的话解释 → 候选反馈建议回看、补先修、补写理由或独立检验。学习地图入口携带具体缺口，用户确认后才生成。

这是一项产品方向选择，未据此声称方法独创或优于已有导师系统。重点是把课堂内容、学习者自报状态、可定位依据与真实作答连在一起，避免只积累越来越多的摘要。

诊断使用 MathPath 当前数学模型，不重新读取原视频；只发送所选内容及前后各一项上下文，总上下文受限于 32000 字符。引文必须是提供片段原有 `source_summary` 中的连续文本，模型不能自填视频时间。该约束检查文本定位，不证明原视频识别或数学解释正确。

每次解释反馈最多使用本条诊断最近两次作答及候选意见，不读取其他课堂或学习历史。旧意见仍标为待核对；相符反馈不改写掌握状态。用户可保留疑问并开始新诊断、删除单条记录，或随课堂笔记导出全部诊断与作答。

请求编号用于避免同一问题或作答的重试重复计费；同编号改变内容会被拒绝。停止等待不代表已取消服务端请求，刷新历史可以找回稍后保存的结果。课堂或诊断在请求期间被删除后，迟到结果不得重建记录。切换片段时不会把旧检查题套到新内容，未提交解释在当前页面按对应诊断暂存。

新增验证：12 项后台离线检查，覆盖可定位引文、非法来源、同编号冲突、作答历史、跨课堂隔离、上下文边界、并发请求、删除后迟到结果、导出与保守反馈；新增前端检查覆盖显式模型选择、引用校验、历史恢复、重试编号、草稿保持与切换隔离。隐藏 WebView2 的宽窄窗口检查使用合成片段与本地对照，通过历史和问题恢复、公式显示及无横向越界检查，未调用真实模型。

真实评估需另外核对：卡点分类是否合理、先修是否够用、检查题能否区分理解与复述、反馈是否尊重等价解法，以及真实学习者是否因此更容易继续学习。目前没有将软件检查数量、引用能定位或模型候选反馈当作教学效果证据。
