# 课堂解析与同步笔记（v0.6.4）

Windows 本机识别 + 当前 MathPath 数学模型。无需 Gemini、额外视频密钥或年龄验证。

## 直接使用

1. 打开 MathPath，确认首页已连接自己的数学模型。
2. Canvas 配好伴学扩展后，回放侧栏点“生成解析”；或在“课堂解析”上传视频后点“生成解析”。
3. 默认从 00:00 到完整视频结尾。首次自动下载约 238 MB 组件并校验哈希，显示进度；后续复用。
4. 每完成一段，右栏就能读笔记，按播放时间定位；选择 A 系统学习、B 问答习题、C 讲授顺序。可以固定阅读、提问、伴学全屏。
5. 展开“对照原画面”核对公式。需要另存笔记时，选择本地保存和目录；未选择不额外导出。

## 识别与来源

本机 FFmpeg 提取声音和每分钟抽样画面；whisper.cpp 的多语言 small-q5_1 权重转写语音，Windows OCR 识别已安装语言。原视频、声音及画面不上传给文字模型；带时间戳的转写和 OCR 文字交给你当前选择的 MathPath 连接整理，不自动换用其他服务。识别本身无 API 费用，文字整理按所选连接的额度规则计费。

文字模型没有直接观看视频或图片。手写数学、复杂图形、符号条件和快速变化的板书容易漏读或误读。本方案处理全片时间范围，不能保证完整还原每个证明或公式；已处理比例不是数学正确率。原课堂摘要、辅助解释、补充习题与疑问分开保留。听不清、看不清时不应编造结论。

没有可用音轨时使用抽样 OCR 并明确提示；没有安装 Windows 识别语言时保留原画面并提示文字识别不可用。缺失内容不会当作已识别。建议 Windows 10/11 64 位，至少 8 GB 内存；CPU 识别速度因电脑而异。

## 停止、继续与历史

后台逐段保存。停止会终止本机识别子进程，已有笔记及转写/OCR 材料保留。再次明确点击生成才继续；失败的文字模型请求不会自动重试，已发出的请求仍可能使用额度。继续须保持同一数学连接与分段长度，以免不同来源混入旧记录。已完成的课堂重复点击直接复用。

原视频不超过 2 GiB、3 小时。可导出 Markdown/JSON；删除课堂会一并删除该课堂视频、识别材料、截图与诊断。原“完整备份学习库”不包含课堂和科研目录，请另外备份 `%LOCALAPPDATA%/MathPath/.mathpath/lectures` 与 `research-memory`。识别工具在 `local-video/runtime`，可以再次下载，不包含个人课堂内容。

## 从卡点到下一步学习

围绕具体片段提问，写明自己已有基础；可诊断先修缺口、符号混淆或省略步骤，给出修补建议和检查题。先写自己的解释，再看提示或参考。模型判断是待核对候选，不自动标记掌握或宣告证明正确。卡点及作答随课堂保存，可导出或单独删除。

## 组件来源与检查

- [whisper.cpp 官方项目](https://github.com/ggml-org/whisper.cpp)：Windows CPU 构建 b5454，MIT。
- [Whisper 官方权重转换仓库](https://huggingface.co/ggerganov/whisper.cpp)：small 多语言 q5_1，下载后按固定 SHA-256 校验。
- [imageio-ffmpeg](https://pypi.org/project/imageio-ffmpeg/) 0.8.1 Windows 轮包中的 FFmpeg；随下载保留其版权及许可文件。
- [Windows OCR 文档](https://learn.microsoft.com/en-us/uwp/api/windows.media.ocr.ocrengine)：使用本机已安装的识别语言。

软件检查、合成语音/画面识别和真实课堂数学效果分别报告。没有把离线测试数量或合成测试当作真实课堂准确率。
