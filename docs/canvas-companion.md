# Canvas 伴学、科研起点与定理记忆

本页描述 v0.6.2 Windows 预览包和当前源码，配套扩展为 0.2.1。新版增加自动记忆、五步指引与可选笔记；使用前关闭旧程序，移除旧版扩展后加载新包中的扩展。

## 开始与结束

- **已有研究问题**：开始时写清目标、已有结果、试过的方法与基础。保存为本机研究工作区，点击“研究指引”得到条件整理、先修与可验证的下一步。构图时可在首页选择此背景。背景只影响下一次生成，不改写既有学习历史。
- **先学习，再探索**：先选具体学习目标；在课后入口单独填写公开英文关键词，查询近期 arXiv 文献。可明确勾选用当前数学模型整理小课题的切入点、先修与第一步。
- **只学习**：不要求填写研究问题，也不自动请求研究建议。

模型指引是候选意见，不表示已解决问题、完成文献查新、证明某个方向尚未研究或保证可发表。文献搜索保留首次提交日期、原文链接、检索时间与 730 天窗口；只看标题摘要不能替代阅读全文。优先检查检索结果的相关性，多个英文词默认取 AND；结果太少可缩短关键词。网络失败显示检索失败，不以模型编造论文代替。

## 安装与配对

1. 启动 v0.6.2 Windows 程序并保持运行，菜单“Canvas 伴学设置（在浏览器打开）”显示实际本机地址与五步指引。使用源码时运行 `start.cmd`；本机已有旧服务时先正常关闭，启动器不会替换已运行的代码。
2. 在 Chrome / Edge 扩展管理页开启开发者模式，加载 `browser-extension/mathpath-canvas`。也可解压 `outputs/canvas-companion/MathPath-Canvas-Companion-0.1.0.zip` 后加载其中的同名文件夹。
3. 点击扩展图标，填写本机 MathPath 的实际地址，源码默认 `http://127.0.0.1:8000`。点击连接，在新打开的本机设置页阅读范围并点允许。
4. 刷新回放，打开右下角伴学侧栏。关联**同一节**已经解析的课堂，再核对时间偏移。扩展不会根据页面标题或带鉴权的回放地址自动猜测是哪节课。

权限仅涵盖交大 `oc.sjtu.edu.cn`、`v.sjtu.edu.cn` 与本机试验页 `/canvas-demo`。不使用 Canvas/JAccount Cookie，不读取视频 `src`/`currentSrc`，不抓课程接口或保存带签名的回放 URL。扩展不能访问模型设置、登录、学习库接口。用户授权后的配对令牌在服务端用 Windows DPAPI 保存，在浏览器只供扩展后台使用，30 天到期，可以从本机工作台撤销。

这是一对一配对：重新配对会替换旧连接。扩展支持同一浏览器的多个回放窗口；每个窗口独立选择课堂和研究背景。未安装扩展的浏览器无法完成页面授权；请从该浏览器的扩展图标重新发起。

## 时间定位与全屏

可访问的 HTML 视频提供播放时间与标准字幕。已有课堂解析按精确区间 `start <= time + offset < end` 定位；不把相邻片段当成当前位置。缺段或没有材料会明确显示，用户可补充当前字幕。网站自定义字幕、未授权的跨域播放器、画在 canvas 中的内容不保证可读取。

“解释当前片段”与“发送问题”是明确的模型调用，使用 MathPath 当前数学模型。解释可包含受限 SVG 图元绘制的几何 / 结构示意，图注明确表示辅助图，并非原板书。问答附上对应时间，最近最多六轮只存在此窗口；切换课堂或研究背景时清空，刷新也清空。模型错误不会自动改变掌握状态。

“伴学全屏”将原视频元素与侧栏放入同一临时全屏容器，临时启用浏览器视频控制条。退出时恢复视频位置、原样式与控制设置；维持退出时的播放位置。播放器框架可能拒绝全屏，或网站的自定义脚本可能不允许移动视频。这些情况用 F11 或在独立课堂实录页打开。网站自己的视频原生全屏仅显示视频，无法叠加旁边的网页内容。

没有标准字幕或预先解析时，本版不会自动理解原视频或板书。课堂解析的上传 / 多模态模型流程见 [课堂解析说明](classroom.md)。浏览器扩展本身不上传原视频。

## 定理记忆

数据在 MathPath 数据目录下 `.mathpath/research-memory/`：

```text
workspaces/<工作区 UUID>.json
theorems/<定理名称>__<UUID 前八位>.md
theorems/<UUID>.json
versions/<UUID>/r<旧版本号>.md
```

常见定理仍保存采用的具体版本、对象与条件，避免相同名字下混用不同版本。非标准 / 不确定的定理保存完整陈述、假设、量词、出处、证明线索、直观与疑问。信息不足时默认标“陈述待补全，不能直接引用”。AI 不会自动勾选“完整”或“已核对”。

同名不同陈述分别建档；同一陈述重复保存会返回已有记录。编辑应从工作台的已有条目进入，保存时检查版本号，过期窗口不能覆盖新版本。旧 Markdown 另存于 versions。修改已有陈述的核对状态时，也应进入已有条目的编辑入口。

AI 会自动归档、去重和更新定理。当前选定工作区的候选也会作为待核对提醒被检索，不能混作已证研究前提；用户核对过的条目单独标记且不会被 AI 覆写。检索有相关性与长度限制，尚不是语义向量检索或形式证明验证。笔记导出另外勾选，Type A/B/C 与保存路径见 [笔记说明](notes-and-memory.md)。

原“学习历史 / 项目”与研究工作区是两个入口；当前未自动迁移或合并。原整库备份不包含课堂文件和 research-memory，需单独保管文件夹或下载相应 Markdown。不要把个人研究数据、视频、API 配置或配对令牌打进对外的扩展 ZIP。

## 验证与范围

离线检查使用临时数据、合成课堂、假模型回答和假 arXiv Feed，检查配对来源、令牌到期/撤销、时间空段、研究背景隔离、定理完整性、旧版保存、近期日期过滤与引用编号。另有扩展后台的 Chrome API 模拟检查。运行：

```powershell
.\.venv\Scripts\python.exe -B tests\run_offline.py
node tests\frontend_companion.cjs
.\.venv\Scripts\python.exe -B packaging\build_companion.py
```

原有学习地图、AND/OR 与课堂前端套件仍单独运行。原生隐藏 WebView 只检查自己的合成页面、公式、图示、安全文本、过期回答隔离、临时数据写入与布局；这不是已安装扩展在 Canvas 上的验收，也不是数学正确性或学习效果评测。真实 Canvas 页面当时由另一个浏览器会话占用，未改动该会话，未安装扩展到用户浏览器。配对、真实回放及全屏仍需现场联调。

arXiv 公开关键词的真实检索已单独验证能返回近期日期；未发送私人研究问题，未调用收费模型。扩展与网站 DOM 模拟检查不能证明跨域播放器兼容性。

参考：[Chrome 内容脚本](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)、[外部消息配对](https://developer.chrome.com/docs/extensions/reference/manifest/externally-connectable)、[Fullscreen API](https://developer.mozilla.org/en-US/docs/Web/API/Fullscreen_API/Guide)、[arXiv API](https://info.arxiv.org/help/api/user-manual.html)。
