# 自动记忆与 Type A/B/C 笔记（v0.6.1）

## 记忆由 AI 管理

无需逐条选择“保存定理”。课堂解析识别到定理时直接归档；学习卡、回放解释和提问的模型响应同时输出需要保留的定理，系统自动保存 Markdown、去重，并为同一来源的更新保留旧版。生成笔记时，其中的定理也进入记忆库。这个整理过程复用已有模型回答，不单独发起一个“记忆模型”请求。

常见定理记录采用版本、条件和出处；非标准定理保留完整陈述、量词、假设与缺口。只有名称或来源不足时明确标注“陈述待补全”，不根据名称补出看似完整的定理。自动归档不意味着经过数学证明验证。

候选记忆可以由 AI 检索出来作回查提醒，带有来源与待核对标记；它们不会冒充已证事实。相关性筛选和总长度上限控制进入上下文的内容。不同研究工作区保持隔离；已有由用户核对的记录不会被 AI 覆写。工作台默认展示记忆列表，用户需要纠错时才打开编辑表单。

数据目录仍为 `.mathpath/research-memory/`，每个定理一份带名称的 Markdown，旧版保存在 versions。记录有规模上限，不是无限存储或形式化知识库。

## 笔记导出由用户勾选

学习地图、课堂解析、科研工作台都有“保存对应笔记（可选）”。默认不勾选，打开页面、修改类型与目录都不生成笔记。勾选后可以手动点击“生成并保存”，或在当前内容下一次生成后自动保存；自动队列有上限，关闭开关后不再发送后续请求，已发送请求仍可能完成。

回放侧栏也有单独的“同时保存对应笔记”开关，默认关闭。勾选后，本次解释完成时再整理一份笔记；整理使用当前数学模型，是一次额外的明确选择的模型调用。关闭笔记开关不会关闭自动定理记忆。

可选择已解析课堂、保存的学习记录、当前学习卡，或手动粘贴数学材料。过长材料会要求缩小范围，不把不完整内容称为整节课的完全覆盖。生成内容均为 AI 草稿，需核对原文与数学论证。

## 类型与分类约定

| 类型 | 内容结构 | 默认保存位置 |
| --- | --- | --- |
| A：系统学习 | 开头列主要结论，正文讲定义、例子和直观，证明集中附录；结论和证明双向链接 | 根目录 / 课程分类 |
| B：问题与答案 | 只组织题目与参考答案，不添加独立综述和证明附录 | 根目录 / 课程分类 |
| C：讲课笔记 | 按讲授顺序，逐一定理说明意义、后续工作、条件和边界、证明关键想法、实际推理的理解检查 | 根目录 / Type C 讲课笔记 / 课程分类 |

可选择 A/B/C、内容日期与课程分类。日期优先填写实际上课日期；每次单独新建 `YYYY-MM-DD_主题__短编号` 文件，不追加到总笔记，也不覆盖旧文件。同一份笔记的 Markdown、TeX、PDF 使用相同文件名主体。

课程分类可由 AI 从所选根目录的分类与常见数学课程中选择，也可手动指定。模型不能提供任意文件夹路径，系统不会让模型改写保存根目录。

桌面版点击“选择文件夹”打开系统选择框；在普通浏览器使用时也可以粘贴本机目录。生成前会使用当前填写的位置。配置在另一个窗口变化时会要求重新确认，防止悄悄存到别处。

## PDF 与同步

默认可生成 Markdown 与 TeX；勾选 PDF 时调用本机 XeLaTeX / TeX Live，运行两遍并检查文件、页数和内部目标。A 型要求每个结论 / 证明的双向目标存在且可解析。缺少编译器、缺字或编译失败时保留源文件并明确说明 PDF 未完成。

程序只从结构化文字生成受限的 TeX，普通文字转义，数学命令受限，不接受模型提供的文档代码、文件读取或 shell 命令。编译禁用 shell escape。软件本身不捆绑完整 TeX Live，也不会自动安装大型运行环境。

可勾选同步到指定目录；源文件与 PDF 逐个核对哈希一致。当前电脑的默认 notebook / iCloud 目录可作为预填项，其他使用者需要选择自己的位置。同步失败只报告未完成，不覆盖不同内容的已有文件。

PDF 结构、链接与编译检查不能证明数学正确或保证所有模型生成内容的排版。缺少完整论证时，A/C 都明确显示“证明待补全”。

## 检查范围

离线检查使用临时目录、合成资料和模型替身，涵盖开关、分类、命名、不覆盖、重复请求去重、旧版本、候选记忆隔离、保存目录变化、TeX 指令转义和文件下载。

另用真实 XeLaTeX 编译合成 A/B/C 笔记，检查实际 PDF 内部目标及同步副本字节一致；隐藏 WebView 检查开关关闭时没有笔记调用、C 型笔记确实存到所选目录、五步 Canvas 指引与宽窄布局。没有调用用户的真实模型，没有据此声称教学效果或真实 Canvas 播放器已通过验收。

原“完整备份学习库”尚不包含 research-memory、课堂视频及这些外部导出文件。请单独保管这些目录；对外分享软件包时不包含个人笔记、记忆、视频或账号配置。
