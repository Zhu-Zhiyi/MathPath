# MathPath Canvas 伴学扩展 0.2.0（预览版）

配套后端是 MathPath v0.6.1 Windows 预览版或更新后的源码。加载新版前移除旧版伴学扩展，以免出现重复侧栏。

1. 先关闭旧版程序，启动 MathPath v0.6.1 Windows 程序并保持运行。使用源码时在项目文件夹双击 `start.cmd`；旧服务还在运行时请先正常关闭再启动。
2. Chrome 打开 `chrome://extensions`，或 Edge 打开 `edge://extensions`，开启“开发者模式”，点击“加载已解压的扩展程序”，选择本文件所在的 `mathpath-canvas` 文件夹。
3. 主程序菜单选择“Canvas 伴学设置（在浏览器打开）”，浏览器地址栏中的 `http://127.0.0.1:端口` 就是本机地址。点击该浏览器的扩展图标，填写此地址（源码默认 `http://127.0.0.1:8000`），点击连接，在新打开的本机设置页点允许。账号或 API 密钥没有写进扩展包。
4. 刷新交大 Canvas / 课堂实录回放页面，点击“MathPath 伴学”。在侧栏选对应的课堂解析，确认相同回放，校准时间偏移。已有解析按时间定位，不会自动识别这节课的身份。
5. 没有解析时，可用播放器的标准字幕或手动粘贴当前内容。网站自定义字幕、未获授权的跨域播放器可能无法读取。扩展不自动上传原视频，也不声称实时看到了板书。
6. 点侧栏“伴学全屏”。它临时使用原视频元素与浏览器标准控制条，退出时恢复原位置；网站自己的视频原生全屏只能显示视频。框架拒绝全屏时可用 F11，或在独立课堂实录页面打开。实际课堂播放器兼容性仍需现场检查。
7. 开始前可以写研究问题 / 选择学习后探索。在底部填公开英文关键词检索近两年 arXiv 论文；勾选整理建议才会调用模型。建议基于标题摘要，不能代替全文阅读与查新。
8. AI 会在课堂解析、解释与提问时自动整理定理记忆，无需逐条点击保存。常见定理保留版本和条件，非标准定理保存完整陈述与缺口。未核对内容供回查提醒，不作为已证事实；需要更正时再打开编辑器，旧版会保留。
9. 可勾选“同时保存对应笔记”，选择 Type A/B/C 和内容日期。点击“选择保存位置”进入本机工作台，可选择根目录；AI 按课程归类，C 单独存放。默认保存 Markdown、TeX，PDF 需要本机 TeX Live / XeLaTeX。笔记整理是另一次明确选择的模型调用，未勾选就不会导出。

默认不开启自动模型调用。解释、提问、研究指引与勾选的研究线索整理使用 MathPath 当前数学模型设置和相应额度。字幕、课堂内容、所选研究背景与最多 6 轮近期问答随请求发给该模型；arXiv 只接收公开关键词。问答暂存在此窗口，刷新会清空，需要长期保留的定理请保存。

权限范围：交大 `oc.sjtu.edu.cn`、`v.sjtu.edu.cn`，以及本机回放试验页 `/canvas-demo`。不读取 Canvas/JAccount 登录信息，不读取回放地址，不抓取课程接口；连接令牌只放在扩展后台，30 天到期。在本机“科研 / 定理工作台”可撤销配对。扩展不接触模型密钥。

这个 ZIP 只包含公开扩展文件；Python 后端、API 配置与个人学习数据不在其中。研究工作区与定理 Markdown 在 MathPath 数据目录 `.mathpath/research-memory/`，当前不包含在原学习库整库备份中，需单独保管。
