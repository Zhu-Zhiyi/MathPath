# MathPath Canvas 伴学扩展 0.4.0（预览版）

配套 MathPath v0.6.4。旧程序正常退出，旧扩展移除后加载新版。

1. 运行 MathPath，首页连接自己的数学模型。已有连接继续使用，不需要 Gemini。
2. Chrome / Edge 扩展管理页开启开发者模式，加载本文件所在的文件夹。
3. MathPath 菜单打开“Canvas 伴学设置”，将浏览器地址栏的本机地址填入扩展图标的连接框，连接后在本机页允许。
4. 刷新课堂实录网页，展开“MathPath 伴学”，点“生成解析”。默认当前主画面整段视频，从 00:00 到结尾，自动关联右栏笔记。
5. 首次自动下载约 238 MB 本机识别组件，无视频 API 密钥或年龄验证。声音在本机转写、抽样板书在本机 OCR；只把识别文字交给当前数学模型整理。视频和截图保留在本机。
6. 右栏随播放定位，展开原画面核对公式；点击“伴学全屏”保留侧栏。可停止并继续，成功片段不会重新生成。实际站点兼容性需要现场检查。

手写公式、图形和板书变化可能识别不全，文字模型没有直接观看视频，笔记需要核对。支持浏览器可读取的完整 MP4/WebM；分段或受保护播放器会明确提示。

AI 自动整理定理记忆，无需逐条保存；未核对定理仍是候选。按需填写研究问题、提问、查近期文献。另存笔记可选 Type A/B/C 和根目录；未勾选不额外导出。

扩展仅限交大 Canvas / 课堂实录及本机试验页。不读取登录 Cookie。点击生成时以匿名 CORS 读取完整视频字节；签名地址仅在浏览器内使用，不交给模型或后端、不写磁盘。配对令牌仅供后台使用，不向网页暴露，也不读取模型密钥。本 ZIP 不含后端程序、账号或学习数据。
